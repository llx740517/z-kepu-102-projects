# Z-科普：102 个 GitHub 项目汇总

这是一个 GitHub 汇总仓库，包含清单中的 102 个项目，按本仓库创建时各上游默认分支的提交固定版本。每个编号目录都是一个 **Git submodule（子仓库引用）**，指向原作者的 GitHub 仓库。

## 一次性获取全部项目

```bash
git clone --recurse-submodules --shallow-submodules https://github.com/llx740517/z-kepu-102-projects.git
```

这会将 102 个项目的完整当前工作文件下载到各自目录；`--shallow-submodules` 只取固定版本所需的浅历史，显著减少下载量。已有本仓库时，可运行：

```bash
git submodule update --init --recursive --depth 1
```

## 仓库结构与更新

- `.gitmodules`：102 个上游地址。
- `项目索引.csv`、`项目索引.json`：项目路径、上游链接和本次固定的上游提交。
- 编号目录：GitHub 页面会显示为可点击的子仓库引用；克隆时填充对应源码。
- 更新某个上游后，父仓库需要提交新的子模块指针，才能记录新的版本。

## 版权与许可

本仓库不复制或重新许可上游代码。每个项目仍由原作者/组织维护；使用、修改或再分发时，需遵守对应上游仓库的 LICENSE、NOTICE 和素材许可。此汇总仓库只记录来源、目录和固定提交。

## 范围说明

这是一个“一个网址、一条命令获取 102 个项目”的汇总仓库，不是把 102 份代码复制成一个新的单体仓库。GitHub 将源码仍存放在各自的上游项目中，子模块引用记录本次固定版本。
